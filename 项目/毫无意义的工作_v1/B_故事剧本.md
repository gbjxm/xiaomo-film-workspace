## 当前故事核心

一句话故事：一个被职场耗空的年轻女职员意外获得让城市组成部分局部消失的能力；她在一连串看似痛快的测试中扩大自己的判断权，直到手机反噬让代价落到自己身上，最终在陌生劳动者与流浪猫面前承认疲惫，从“删除问题”转向“留下生命”。

人物弧光：明朗投入并用“好的，没问题”适应规则 → 把疲惫外化为删除公司与城市问题 → 因正反馈相信自己能判断什么该消失 → 手机反噬后失去控制 → 接受环卫奶奶的帮助并主动替长发乘客处理后果 → 向小猫承认“不想变成大人” → 不再让事物消失，而是留下小七。

观众承诺：前半提供现代职场共情与愿望成真式荒诞喜剧，中点以后把“消失很好玩”反转为数字依赖、劳动报酬、责任和成长焦虑；结尾给予温柔余韵，不解释世界规则百科。

## 历史故事核心（v0.6，停用）

原始种子：受《毫无意义的工作》的“假设一种工作消失，会给城市带来什么影响”启发，以一名被职场耗空的年轻人亲历职业消失实验，讽刺当代年轻人对薪酬、大厂、学历、资历和忙碌的追逐，并重新追问劳动的真实作用。

最想保留的直觉：小莫从明朗、兴奋和主动投入逐渐变得疲惫麻木；她躺在贴满电影海报的房间里，却因精力耗尽只能刷低负担短剧。公司消失后的整日经历先以外卖、理发、管理和游戏制造荒诞喜剧，手机消失后突然减速；雨中环卫奶奶的普通善意继续蓄压，最终由开头出现过的小猫触发小莫对青春投入和工作意义的情绪崩溃。她哭着说“我不想变成大人”以后才显现为小女孩，最后以家中熟睡的小莫和客厅临时猫窝收束。

主角与关系：小莫，约 25—26 岁、刚进入新公司并在时间推移中承担越来越多工作负担的年轻女职员。她与公司的关系从主动投入、渴望证明自己，转为被会议、加班、替人工作和带新人持续消耗；电影海报连接着曾经的兴趣与现在的生活。闺蜜是职场处境的现实对照，环卫奶奶提供陌生人的具体善意，小猫承接小莫开场尚存的柔软与结尾卸下防御的情绪。

主角想要什么：起初想通过积极工作、学历、证书和竞争进入体面、稳定且被认可的生活。公司消失后，她先想解决工资和去处的现实问题；早餐、理发和管理压力的变化又使她逐渐把能力当成改善城市、判断“什么没了反而更好”的工具。她的深层欲望仍是证明多年投入没有白费，并确认自己没有选错生活。

阻力与冲突：外部阻力是会议、加班、工作表演与社会评价对生活的长期挤压，以及消失设想不断产生的意外后果；内部冲突是她已经怀疑学历、薪资、头衔和忙碌，却仍依赖这些东西证明自己的价值。外卖、游戏和管理变化不断修正她的判断，手机消失又使代价直接落到她本人，奶奶的善意则迫使她无法继续只把劳动者当作抽象职业样本。

变化方向：积极投入 → 身心耗竭 → 随口否定公司 → 公司真的消失 → 用早餐外卖、理发服务和管理压力测试外部世界 → 通过盲道、闯红灯、商业广告和电子游戏的连续测试获得控制感 → 智能手机消失、控制反噬到本人 → 被迫安静并重新接触现实生活 → 在雨中接受环卫奶奶的帮助 → 回家路上持续压抑并觉察自己的功利判断 → 小猫触发对高中、大学、求职和工作的整体崩溃 → 哭着承认“不想变成大人”并显现为小女孩 → 选择带猫回家 → 给猫洗澡、搭窝并一起睡着，进入工作问题未解决但生活已发生细小变化的新状态。

题材、背景与规则：当代城市职场黑色喜剧／荒诞寓言，结构预算约 510 秒。故事先用现实职场建立小莫的耗竭，再进入荒诞层：小莫必须形成一个完整的消失念头，并让观众能够清楚听见或理解这个完整念头；她可以说出口，也可以只在心里完整想出。变化只在她当时所在的一小片区域内被明确表现，影片不证明也不否认更大范围。结果持续多久、能否撤回、是否恢复以及是否可能是梦仍待确定。

主题或情绪方向：不以薪资、学历、头衔、体面程度、忙碌程度或单一“不可替代性”直接判断劳动与人的价值。作品通过不同消失结果讽刺无效管理、重复汇报和现代生活中的替罪式抱怨，也保留反论：不可替代的工作仍可能低薪、疲惫和缺乏尊严；看似影响不大的工作也不等于从事者没有价值。情绪从职场疲惫进入荒诞欢快，在手机反噬后转为安静、孤独、陌生善意和个人崩溃。

结尾方向：当前采用的版本仍以小猫触发全片唯一的情绪高潮。小莫先倾诉并哭着说出“我不想变成大人”，随后显现为小女孩。猫准备离开时，她第一次不再删除问题，而是主动邀请猫先跟自己回家。故事以小女孩状态的小莫给猫洗澡、搭临时猫窝、猫跳上床并与她一起睡着收束；不解决工作去向。是否继续追加第二天恢复或梦境式诙谐尾声保持待定。

### 《毫无意义的工作》故事大纲

#### 开场：暂时留出的十五秒

影片先从后半段截取一个荒诞、有趣的片段作为开场，让观众先看到“这个世界有些不对劲”。具体截取哪一段暂时没有确定，但不提前泄露手机反噬、小女孩变化和最终结局。

十五秒后，故事回到小莫刚入职的时候。

#### 第一幕：公司真的消失了

天气晴朗。

小莫戴着新工牌走进一家自己曾经很想去的公司。她对一切都感到新鲜，主动跟同事打招呼，认真记录前辈交代的工作。最开始，她愿意接活，也愿意加班。前辈把文件交给她时，她总是很快回答：“好的，没问题。”

时间不断向前。她参加的会议越来越多，会议刚结束，新的会议通知又弹出来。老员工把没处理完的工作交给她，新员工遇到问题也来找她。工位上的文件越堆越高，窗外从阳光明亮变成阴天，再变成深夜。她的回答也从“好的，没问题”，慢慢变成疲惫的：“好……我一会儿弄。”

一天深夜，小莫拖着身体往家走。路边传来猫叫，她停下来，看见小猫（流浪状态）躲在角落里。

小莫蹲下来，从包里翻出一根火腿肠：“你还没吃饭呀？”

她撕开包装递给小猫：“刚好还有一根。中午从公司顺的，便宜你了。”

猫低头吃东西。小莫摸了摸它，疲惫的神情终于松下来：“你好可爱啊。”

她陪猫待了一会儿。准备离开时，又回头看了它好几次：“我还是先把自己养活，再考虑养你吧。”

小莫回到房间，整个人倒在床上。墙上贴着她喜欢的电影海报，可她已经没有精力完整看完一部电影，只能不停地刷穿越、系统和搞笑短剧。

屏幕里的人物不断逆袭、重生、绑定系统。小莫机械地向上划：“人家都有系统……”

她把手机举到脸前，又无力地放下：“要是公司没了就好了。”

第二天早上，闹铃响起。小莫猛地惊醒，匆忙穿衣、洗漱、挤地铁。出站后，她一路狂奔，爬上楼梯，冲向公司。

“完了完了，要迟到了。”

她终于赶到，扶着腿喘气：“还好，还好，没迟到……”

小莫抬起头。公司所在的整栋楼消失了，原来的位置只剩下一片空地。

她愣了几秒：“我去……公司没了？”

她立刻给闺蜜打电话：“可能你不信，我公司没了。”

闺蜜压低声音：“懂你意思。没事，我公司也快没了。”

“不是，我是说它真没了。整栋楼都没了。”

“你想辞职就辞呗，反正你们公司天天九九六——”

“不是辞职！楼没了！工资还没发呢！”

电话另一边传来脚步声。闺蜜的声音忽然更低：“不跟你说了，我主管过来了。最近他可严了，要是看见我上班打电话，又该扣工资了。先挂了啊。”

电话断掉。小莫站在空地前，不知道还能做什么。

过了一会儿，她叹了口气：“事已至此，先去吃个饭吧。”

#### 第二幕：原来消失也挺好玩

小莫打开导航，找到一家自己经常点外卖的早餐店。到了店里她才发现，自己虽然吃过很多次这里的东西，却从来没有真正进来过。

柜台上堆满外卖袋，门口站着等餐的骑手，店内座位反而没有多少人。

小莫对老板说：“老板，来杯豆浆，一根油条，再加个卤蛋。”

老板头也没抬：“打包得等会儿，前面还有好几单。”

“我不打包，就在这儿吃。”

老板抬头看了她一眼：“行嘞，你先坐，我一会儿给你端过去。”

小莫坐下吃早餐，感叹自己好久没有在店里正经吃过早饭。旁边的大爷问她是不是学生，她说自己在附近工作。

大爷说：“上班的啊？现在早上能在店里看见年轻人，还挺少见。一个个不是不吃，就是随便点点外卖。早餐还是得好好吃。”

小莫点点头。她想起自己以前每天早上只喝咖啡，饿到胃疼也要赶着打卡。她看向柜台上的外卖袋：“要是早餐外卖没了，会怎么样？”

下一刻，店里瞬间拥挤起来。原本等外卖的人全都来到店里。有人拎着公文包打电话，有人不断看时间，还有人挤在柜台前催促。

“老板，我九点要打卡！”

“我先来的！”

“我都等十分钟了！”

“老板快点，我迟到要扣钱的！”

刚才还很安静的早餐店转眼变成另一个早高峰。小莫捧着豆浆，默默往旁边挪了挪。

离开早餐店后，小莫经过一家理发店。她摸了摸因为一路狂奔而乱掉的头发，想起自己之前在这里办过卡，便走了进去。

洗完头，理发师站到她身后。小莫看着镜子，忽然想到：“要是没有理发这回事，会怎么样？”

理发师再抬起头时，已经顶着一头拖到地面的长发，胡子也垂在胸前。他像什么都没发生一样问：“洗完了，接下来怎么弄？”

小莫盯着他：“你……你不给我剪吗？”

“剪？谁会那玩意儿？”

小莫从椅子上跳起来，冲出理发店。街上的人全都留着夸张的长发和胡子。有人把头发盘在头顶，有人拖着头发赶公交，还有人被自己的胡子绊了一跤。

小莫冲进地铁，发现车厢里也是一群长发人。有人把胡子绕在胳膊上，若无其事地玩手机，车厢广播里偏偏响起护发素广告。

她赶紧下车，一路跑出这片区域。看到周围的人恢复正常后，她扶着墙喘气：“终于正常了……”

小莫发现自己来到了闺蜜公司的办公园区。她看着一栋栋写字楼，想起闺蜜每天都在抱怨主管：上班不能回消息，下班后还要写日报、周报，开完会还要再开一个复盘会。

小莫试探着说：“要是那些只会催日报、扣工资的主管岗没了……公司还转吗？”

周围毫无变化。写字楼还立在那里，人们照常进出。

小莫等了一会儿：“就这？没变化嘛。”

电话忽然响了，是闺蜜。这次闺蜜说话很大声，整个人明显轻松了：“你怎么样了？公司找着没？”

“还没。你今天怎么敢这么大声说话？”

“什么敢不敢的？我们有事直接跟老板说就行了。”

闺蜜告诉她，最近不用写周报，也不用留下来开无意义的会：“对了，我订了两张电影票。”

小莫马上高兴起来：“真的吗？”

“真的啊。你要去吗？”

小莫故意停顿：“没有，我就是替你高兴。”

“那我找别人了。”

“哎，别别别，逗你玩的！当然咱俩去。”

两个人笑起来。挂掉电话以后，小莫心情很好。她抬头看了看天：“今天天气还不错。去公园转一圈吧。”

小莫下地铁，向公园走去。一条盲道被共享单车、电动车和杂物堵得严严实实。她皱眉：“要是这些占盲道的东西都没了就好了。”

话音落下，杂物瞬间消失，车辆自动退到一旁。盲道重新变得完整通畅。小莫有些得意。

来到路口，红灯刚刚亮起。一位妈妈觉得路上没有车，牵着孩子准备直接过去，孩子反而拉住她：“妈妈，不能闯红灯。”

小莫说：“要是闯红灯这回事也没了呢？”

原本准备抢最后几秒、骑车蹭过去的人，全都退回停止线后。所有人站得异常整齐，等到绿灯亮起才一起通过，整齐得甚至有些不自然。

小莫继续往前。公园附近最漂亮、前后反差最大的一个景点，被杂乱的商业广告牌遮住。

“要是这些乱七八糟的广告牌没了呢？”

广告牌消失，同一个景点原本被遮挡的完整风景露出来。小莫越来越兴奋，仿佛正在亲手修改这座城市，把所有不顺眼的东西一项项删掉。

进入公园后，一个孩子蹲在地上玩手机游戏。母亲站在旁边催他：“别玩了，天天就知道玩游戏。”

小莫看见后顺势说道：“那要是电子游戏没了呢？”

电子游戏消失。孩子愣了一下，很快放下手机，找来卡片或其他小游戏，继续蹲在地上玩。

电子游戏没有了，玩耍和娱乐并没有消失。小莫看着孩子，笑容里多了一点疑惑。

#### 第三幕：这次消失的是手机

连续几次测试都没有给小莫造成真正的损失。

她看向孩子放在一旁的手机，又看向自己的手机：“哎，你说那要是手机消失了会怎样？”

手机从她手中彻底消失。公园里其他人的智能手机也同时不见。

小莫反复看向空空的手，又翻遍口袋，什么通讯设备都没有找到。导航、付款、微信和电影票全都跟着不见了。

“不是……我的票呢？”

“我怎么回家？”

“我怎么联系闺蜜？”

她拼命重复刚才的话，想把愿望撤回，却没有任何反应。小莫站在路边翻口袋、抓头发，动作太大，还闪了一下腰：“哎哟，我的腰！”

周围的人却开始适应。有人拿出报纸，有人坐下来聊天，家长陪孩子一起玩纸牌。

刚才玩游戏的孩子指着小莫问：“妈妈，那个姐姐在干什么？”

母亲把孩子拉到身边：“不知道，可能遇到什么事了吧。”

小莫第一次意识到，她并不是站在外面安全地测试世界。这一次，被改变的是她自己的生活。

#### 第四幕：没有手机以后，时间突然慢了

小莫已经走到公园。没有手机，她不知道该做什么。

她在长椅上坐了一会儿，又站起来做了几个俯卧撑。做不动后，她蹲在地上画圈，最后叼着一根草躺在草坪上。

周围有人看书，有人聊天，有人陪孩子玩。起初，小莫觉得无聊得快要发疯，慢慢地却安静下来：“好久没这么安静过了。”

她闭上眼睛，睡着了。

天色渐暗，细雨落在小莫脸上。她醒过来，缩了缩身体：“怎么还下雨了……好冷。”

雨越来越大。小莫赶紧跑到附近避雨。街上的人已经走得差不多了，一位穿着雨衣的环卫奶奶还在清理路边的垃圾。

奶奶看见小莫站在那里，走过来问：“小妮儿，咋还不回家？”

“手机没了，打不了车，也付不了钱。”

“身上没带钱包？”

小莫翻遍口袋，摇摇头。

奶奶看着她：“工作日咋跑公园里睡觉了？”

“我公司没了。”

奶奶愣了一下，以为她在说公司倒闭：“那是够愁人的。”

小莫看着奶奶手里的扫帚：“奶奶，你每天都扫这条街吗？”

“差不多。今天扫完，明天还得扫。”

“那你不觉得……扫了又脏、脏了又扫，没什么意思吗？”

奶奶低头把一片被雨水冲过来的垃圾扫到一边：“啥意思不意思的。今儿扫干净，今儿走路就顺当。明儿脏了，明儿再扫呗。”

小莫沉默了一会儿：“那工资呢？”

奶奶笑了：“工资可不能没。工资没了，俺第一个不干。”

小莫也忍不住笑了一下。

雨小了一些。奶奶把伞递给她：“赶紧回去吧。天都黑了。”

小莫没有马上接：“那您呢？”

“我有雨衣。伞拿着。”

奶奶又从雨衣内袋里摸出一些现金，塞到小莫手里：“身上没钱咋坐车？这个拿着。”

小莫连忙推回去：“不用不用，伞我都不知道怎么还您。”

奶奶把钱和伞一起推给她：“先回家再说。”

奶奶转身继续清扫。

小莫握着伞和现金往家走。她没有立刻哭，只是变得越来越安静。

小莫（高中阶段）在深夜熬夜做题；小莫（大学阶段）准备证书和作品集；小莫（求职阶段）一次又一次修改简历、准备面试、等待内推消息。这些回忆并不壮烈，只是一段又一段重复的深夜。小学、初中阶段是否加入，以及最终采用图片式还是视频式闪回，留待后续确定。

小莫再次挤进地铁。车厢里仍然坐着之前那些长发、长胡子的人。有人已经把头发编成辫子，有人抱着自己的胡子睡觉，护发素广告依然在播放。

放在几个小时前，小莫可能会笑。现在她只是安静地站在那里。

#### 第五幕：我不想变成大人

快到住处时，小莫又看见了开头遇到的小猫（流浪状态）。

她撑着伞走过去，蹲在它面前：“你今天还在啊。”

猫叫了一声。

“我今天可倒霉了。公司没了，早餐外卖没了，理发也没了，最后连手机都被我弄没了。”

她试着把这一切当成笑话，可说着说着，声音慢慢变了。

“我高中三年一直不敢停。别人学，我就得学。别人考证，我也得考。”

“上大学以后，我又做作品集、准备面试、找人内推……我一直觉得，只要能进去就好了。”

“可我真的进去了以后，每天还是开会、汇报、加班，替别人收拾工作。”

“我连一部自己喜欢的电影都看不完。”

她低下头：“那我前面那些年……是不是都白过了？”

猫靠近她。小莫的声音开始发抖：“我不是不想工作。”

“我就是不知道，为什么一定要活成这样。”

她终于哭出来：“我不想变成大人了。”

成年小莫的模样逐渐褪去。蹲在猫面前的人成了小时候的她。

小女孩哭了很久。猫转身准备离开，小莫下意识伸手，轻轻拉住它。

“你要不要……先跟我回家？”

她擦了擦眼泪：“我也不一定养得好。”

“但我们先回去吧。”

家中多了小猫（洗净、戴项圈状态）。小女孩状态的小莫用纸箱、旧衣服和毯子搭了一个临时猫窝。

猫没有睡进窝里，而是直接跳上床。小莫把它抱下去：“虽然刚才给你洗了澡，但还是不要随便上床。”

猫再次跳上来。小莫已经没有力气管它。

房间渐渐安静。墙上的电影海报还在。

小女孩状态的小莫睡着以后，猫趴在她身上，也慢慢闭上眼睛。

公司有没有回来，智能手机有没有恢复，小莫第二天还要不要继续找工作，都不解释。当前版本停在小女孩状态的小莫与猫一起睡着。

她仍然不知道该怎样面对成年人的生活。只是这一次，她没有再让什么东西消失，而是把一个小生命留了下来。
