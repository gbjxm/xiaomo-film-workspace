# 开始这里

> 本项目使用“小陌 AI 影视工作流 v0.8”。新建项目由 `$start-ai-film-project` 从权威模板创建。
> workflowPatch: single-foreground-micropatch-v1
> workflowResume: same-role-resume-v1
> workflowScript: b-word-stage-ready-v1
> 本文件是日常入口；项目根目录以本文件所在目录为准，不依赖旧聊天或旧电脑路径。

## 日常路线

```text
A 分配一个完整阶段任务
→ B/C/D/E 中唯一目标岗位在阶段内处理中小修改
→ 合格跨岗小改由当前任务后台交文件所有者并自动续办
→ 明确确认后写回
→ 更新最近交接
→ 阶段完成或发生重大变化时返回 A
```

A 不把 B/C/D/E 阶段按故事骨架、初稿、单项资产、单次生成、粗剪、单个后期组件或发行字段拆成多个微任务。当前岗位就是本阶段中控：岗位内追问、版本迭代、局部返修和同岗位 Skill 切换直接处理；用户所在任务不等于文件所有权。

跨岗位但功能不变的小改使用“单一前台＋后台所有权微补丁”：用户已采用具体差量并授权记录写入；只涉及当前岗位与一名文件所有者；稳定 ID、制作功能、事件结果、阶段目标、任务包络、Profile/平台/主要传播承诺和授权类别不变；影响可一轮判定并恢复。当前岗位只读预检，所属岗位按预期 hash 写自己的文件；只有既有 A 指针失效时，A 后台同步版本/hash，随后原岗位自动续办。用户不切任务、不复制内部交接。

普通微补丁默认在同一回复内依次调用受限所有者适配器、A 指针适配器和前台重绑，不创建三个完整代理任务；只有需要新的专业判断或无法保证写入白名单时才降级到所有者任务。

“交互前台”是用户停留的任务，“权威执行目标”是 A 当前允许写入的岗位。微补丁保持目标为前台，所有者只执行受限子操作；重大串行路由会临时改变 A 目标，原前台暂停，恢复前不得继续使用旧输入。

用户明确称为重大修改，或新增/删除场景或稳定对象、改变核心事件/动机/关系结果/结局/制作功能、剪辑结构目标、Profile、平台/主要承诺、项目目标/里程碑/任务边界、权利/安全或外部动作类别时交 A。目标 hash 变化、影响超过一名上游所有者或一轮不能闭合也升级 A。正常阶段完成仍只回 A 一次。

完整生产链为：

```text
点子 → 采用 Sxx → 场景导演/资产/色卡/表演/镜头 → Vxx Setup → 提示词 → 逐 take 生成与 C 准入
→ C 精确素材清单 → D 接管 → CUT/锁画 → PIC/AUD/TEXT/GFX → 精确 Master/QC/恢复
→ 包装决定 → 最终封面 → 唯一最终发布包 → 发行就绪检查
→ manual-copy 人工发布 → 真实回执 → 发行结果复盘
```

## 必须遵守的契约

1. 项目文件是长期事实源，聊天记录不是。首次进入任务只读取本文件的共享契约与本岗位启动词，跳过其他岗位启动词；同一任务内未变化的已读内容直接复用。
2. A 每次只分配一个权威执行目标；B/C/D/E 通常只执行 A 当前分配给本岗位的任务。唯一例外是带完整来源/A 指纹、采用证据、记录写入授权和预期 hash 的合格后台所有者请求；它只是当前 A 任务的受限子操作，不成为第二个当前任务。
3. 每个岗位只写自己的主文件和专属目录，其他文件只能读取；当前任务只能发起后台所属岗位执行，不能借微补丁直接代写。
4. 后台微补丁只传来源任务 ID、A 当前任务版本/hash、采用证据、记录写入授权证据、精确对象/版本/hash、差量、不变量、受影响执行坐标、失效范围、外部动作授权和恢复条件，默认一名所有者、一轮完成；A 指针同步不是创作审批，也不算岗位切换或往返次数。
5. 草案阶段零写入。只有“明确采用”才写成采用；暂停、切换岗位或结束本轮只能在明确要求记录时写“待定摘要＋最近交接”。
6. 项目持久采用状态只使用 `待定`、`采用`、`停用`；执行有效性只使用 `未触发`、`进行中`、`已冻结`、`已失效`、`不适用＋原因`。历史采用不因当前失效而被抹除。
7. 草案、咨询、诊断和只读检查不计算 SHA-256。明确采用并即将写入时，先重读目标并记录 SHA-256，紧邻写入前再次核对；值变化时停止，不覆盖。
8. 采用、记录写入、生成媒体、执行剪辑、制作或改写封面媒体、安装、晋升、迁移、上传和公开发布是彼此独立的动作，分别需要明确授权。微补丁的一次记录写入授权只原子覆盖所有者精确对象、必要 A 指针同步和前台引用/失效登记，不授权外部动作。
9. v0.8 首版不自动登录、上传或公开发布；E 只交付经过检查的 `manual-copy` 包。没有真实链接或平台回执时不得登记已发布。
10. 公开发布前必须明确“保留首映或投稿资格：需要 / 不需要”。未确认时不能判就绪；需要时交 A 调用 `$manage-film-competition-submissions` 核实公开条件。
11. A/B/C/D/E 若观察到重复返工、遗漏、交接失败、职责冲突、重复手工步骤、工具失败、证据缺口或契约不清，使用 `$improve-ai-film-workflow` 静默写入 `流程改进日志/`。普通创作修改不记录；日志由该 Skill 独占写入，不自动修改总工作流。
12. 没有可用工具时交付真实的人工执行包，不声称已生成、已剪辑、已制作封面或已发布，也不把内部路由改成让用户手工复制。

13. B/C/D 新聊天先执行 `same-role-resume-v1`：读取本岗位缓存并核对 A 当前任务区段、revision、lease 和缓存点名依赖；有效时只读当前游标的精确必读集。阶段包络不是启动读集，缓存校验不等于正式写入或外部动作授权。
14. `续接缓存/` 是非权威运行缓存，允许在当前对象、待定差量、下一步、授权或依赖发生变化时自动刷新；待定仍是待定。缓存不得保存完整聊天、隐藏推理、媒体内容或长正文，单份不得超过 6,144 UTF-8 字节。
15. 默认不读取旧任务历史；缓存缺失且存在未持久化工作时，最多读取最近 2 个同岗已完成任务摘要。缓存损坏或 hash 漂移时只做区段/对象级恢复，禁止递归扫描完整项目、候选素材树或全部媒体。
16. 本入口已启用 `workflowScript: b-word-stage-ready-v1`：B 与 A 共用唯一 `B_STAGE_READY v1`。B 做专业、详细的创作/正文/制作/证据自检；未 PASS 继续留 B。A 只查遗漏、路径/版本/hash、用户决定、阻塞项、Sxx 范围和任务包络，不重新逐场审创作细节；完整性通过后直接派 C。
17. Word 只在对白、场景动作、故事层连续性、计时和最终文字精修时按需启用。Codex 只能以已保存文件为同步点；用户继续编辑时，Codex 改保存快照的修订/批注副本，不覆盖未同步内容。Word 存在、逐场对齐或文件名含“最终版”都不自动等于采用、写入 B 或释放制作。
18. B 活跃区不堆历史全文，只保存当前剧本工件、版本/hash、Sxx 锚点、待合并冲突和检查结果；旧稿进 `剧本/历史/` 且默认不读。采用源稿不可原地修改，生产稿可选；用户指定原文件为最终版时不得清洁、规范段落、样式或分页。

“采用这个”“按这个定稿”只证明采用；“按这版写入”“就按这个改”“更新这个文件”在对象与差量明确时可同时证明采用和原子记录写入授权；“先看看”“大概这样”“以后再说”仍是待定。遇到含糊表达只问一个最关键的问题。

## B/C/D 同岗续接入口

推荐入口：在旧岗位任务发送一句 `切换到新的 B/C/D 同岗续接任务`。这句话是创建同一项目新本地任务的明确授权；旧任务刷新缓存、准备 handoff、创建 `岗位｜续接NN`，激活新租约后停止写入。创建失败时取消 pending handoff，旧任务继续有效；不自动删除或归档旧任务。

备用入口：用户确认旧岗位任务已经停止后，手动在同一项目新建任务并发送；若新任务仍检测到旧任务活动或无法确认其已停止，不接替，改用上面的推荐入口：

```text
B｜故事剧本同岗续接。这是手动切换，我已停止旧 B 任务。执行项目中的 same-role-resume-v1，领取最新 B 续接缓存；只读恢复，不写项目、不执行外部动作。
```

```text
C｜视觉生成同岗续接。这是手动切换，我已停止旧 C 任务。执行项目中的 same-role-resume-v1，领取最新 C 续接缓存；只读恢复，不写项目、不生成媒体。
```

```text
D｜后期剪辑同岗续接。这是手动切换，我已停止旧 D 任务。执行项目中的 same-role-resume-v1，领取最新 D 续接缓存；只读恢复，不剪辑、不处理声音、不转码或导出。
```

续接完成只回复：续接是否就绪、当前对象/状态、唯一下一步、写入与外部动作授权边界。旧任务若发现租约已变化，必须停止写入并指出当前活动续接任务。

## 问题路由

```text
故事事实、人物动机、事件或因果问题 → B
场景导演、生产设计、表演、摄影灯光意图、镜头、提示词、源画面或生成问题 → C
接管、入片选择、剪辑、声音、画外字幕/GFX、Online、最终调色、成片、Master 与恢复问题 → D
标题、发布文案、发行封面、发布包、平台字段或发行数据 → E
无法判断、权利风险、跨岗位冲突或里程碑关闭 → A
```

一次生成失败或单条发布数据不能直接触发全故事重写。先按真实证据路由到最小责任层。

证据只指向一名其他文件所有者且满足微补丁条件时，当前岗位后台直达该所有者；A 只同步失效指针。其余跨岗位冲突和重大变化由 A 决策。
