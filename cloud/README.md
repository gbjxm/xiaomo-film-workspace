# 私有工作流同步范围

从根 CLOUD-START.md 开始。源入口、24 个正式技能、当前 V1/v0.9、5 个被旧项目依赖的历史协议版本，以及 8 项目的文本/索引/不可变采用内容/恢复事务按来源原字节复制。原 AGENTS 位于 cloud/local-AGENTS.source.md，根 AGENTS 是限定云端候选工作的入口。cloud/source-manifest.json 给出来源别名、相对位置、SHA-256、分类及 Skill 镜像关系；不把云端路径冒充原本机路径。

正文中原有绝对路径保留；本机 lease/token 作为历史记录保留，禁止作为云端活租约。纯锁、临时文件、项目可重建续接缓存、嵌套 Git、维护候选/测试副本、OCR 虚拟环境和原始 OCR 识别缓存、认证文件未包含。协议模板中的默认续接字段保留，不能作为本机租约使用。原 HANDOFF 的维护链接可能指向本机排除区域，它们不是包内已具备的素材。

cloud/media-index.json 区分小体积插图、仅本机存在媒体和无法在来源中定位的引用。仅正文/索引实际引用的媒体计算当前字节 SHA-256；其他媒体只登记体积/相对来源等元数据。媒体缺失不得被解释为媒体质量验收。

所有云端编辑先放独立分支的 cloud/drafts/，交本机原专业运行时审核与受控导入。当前 studio_io.py 拒绝非 Windows 覆盖已有可编辑视图；不在云端调用 Windows 岗位 Claim 或采用事务。skills 的专业知识可读，不等于其脚本、达芬奇、生成服务和任务工具均能执行。

知识树是独立外部系统：知识桥所需 Skills、Vault 与目标环境配置需要由整体三系统仓库计划提供，不从本机 Codex Home 全量复制。
