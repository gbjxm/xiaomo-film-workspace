# 视频反推

按真实镜头与事件的时间顺序重建。视频输入不能被当作一张图处理，也不能用静态关键帧相似代替整段还原。

## 获取足够证据

- 先核实实际文件、时长、画幅、帧率及音轨情况。已有 `ffprobe`、`ffmpeg` 或合适的视频工具时可用于只读探测和分析副本；缺少依赖时不自动安装。
- 优先查看连续视频。可结合切点检测与抽帧建立逐镜底稿，覆盖开头、结尾、重要姿态或表情变化、遮挡变化和转场；快速动作或疑似漏切区域需增加时间采样。
- PySceneDetect 可辅助发现边界，但输出仍需检查，闪光、叠化和镜内运动可能干扰检测。不得把检测结果直接当成已经人工核实的镜头表。
- 工具只能查看帧图时，说明采样时间与实际覆盖；无法区分的推拉、变焦、主体靠近等保持未确定。稀疏帧图不能证明平滑运动、瞬时速度或完整事件经过。
- 声音需要实际读取可用音轨或有对应时间的可靠转写。无声截图不能推断实际对白、音乐、音效；“文件含音轨”也不等于已核听。只有转写时不推断未提供的音色、混音或环境声。
- 所有分析副本与原片分开，保留来源和时间位置。抽帧用于分析和展示证据，不送入纯提示词生成端。

## 逐镜描述

保留真实镜头边界，不预先限制为固定数量的节拍或强制取整数秒。时间统一从用户选定片段的起点计，来源内偏移另记；区间递增且不重叠，精度不超过证据能支持的程度。

每镜根据实际内容写清：

1. 开始状态：主体外观、空间位置、构图、视线、光色及重要背景。
2. 主体动作：起点、动作顺序、方向、接触对象、速度变化、结果状态。
3. 摄影机：固定或移动、运动方向、跟随对象、画面尺度如何变化；与主体自身移动分开。
4. 环境运动：雨、烟、布料、人群等实际可见变化，不能默认补充。
5. 焦点、光线或表情等实际变化，以及有证据的声音。
6. 结束状态、换镜类型和下一镜衔接；真实切镜不能改写成摄影机连续移动。

跨镜头保持主体外观、道具状态和动作承接；源片本来不连续的部分忠实描述，不自动补因果。不能把多镜片段压成一个长镜头，也不能为“丰富镜头语言”增加原片没有的切镜。

## 输出及生成限制

按观看顺序整理完整反推内容稿，交给 `$format-seedance-2-prompt` 后再输出整段最终提示词，镜头时间段在复制层内明确；不直接把逐镜分析稿当作最终模板。已获连续反推与格式化授权时，按格式器的独立反推例外提交观察候选，不要求逐项采用，也不把分析用原片、抽帧或音轨标成生成参考。模型是否支持多镜、声音和所需时长，只有实际核实后才称支持；否则保留文字候选并说明未验证项。

最终交付前由反推者回到已有连续声画证据，逐镜核对实际复制层中的真实切镜与同镜延续、递增且不重叠的时间区间、动作与运镜的触发顺序、对象及作用范围、局部变化与声画同步。同镜分段不能被写成切镜，镜头结束构图不能提前成为起幅；未知时间或未核听的声音仍保持未知。格式器的文字检查不能代替这一步，无法核实的项在框外说明。

返修时先核对被修改句的全部属性，只改变点名属性及直接冲突，保留同句中未点名且仍有证据的状态、范围、时序和同步关系；将上一版完整复制层与精确差量交回同一格式器。正文、摘要和差量不一致时，由反推者依据原片核对并提交唯一当前版本，不让格式器从新旧稿拼接事实；证据仍不足时才提出一个关键问题。

若必须按目标模型限制拆成数段生成，先说明这一安排及后续拼接需要；不得把分段结果宣称为已经还原原片。单张图片测试只能验证该帧的静态描述，不能验证视频运动、节奏、声音或镜头衔接。
