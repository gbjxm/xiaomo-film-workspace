# 纯提示词生成与对照

只有实际参考与真实输出都可查看时才能判断还原效果。请求用户认可前，先完成有证据的专业对照；不能把全部检查推给用户。

## 生成前

明确并记录本轮的完整提示词、目标工具/模型、实际可设的画幅与输出设置，以及用户本次授权的次数或范围。模型名、种子或增强开关不可得就记未知，不编造已锁定值。区分格式器目标名、实际工具和真实底层模型；能取得平台增强/改写后的提示词就另存并与提交稿比较，取不到则标为未知，既不假定有改写，也不把调用边界原文当成最终模型输入已验证。

常规生成采用对应现有图片或视频格式器交付的最终复制层，不跳过格式器，也不把框外分析、诊断建议、候选状态或参考路径混入生成文字。用户明确要求检查模板贡献时，[诊断对照](diagnostic-comparison.md)允许经源图复核的完整中间稿作为独立对照条件；该例外只用于诊断，不改变常规交付。格式化完成或准备好对照文字均不等于已经生成。

本阶段生成端只接收文本与常规设置：新图不传原图或会话图片，文生视频不附参考视频或抽帧。已带参考图的输出可以做差异分析，但不能作为纯提示词能力的验证结果。

用户仅要求反推时先交提示词；已明确要求生成则直接执行，不重复索要同一授权。图片测试优先评估新参考的第一次直出，同一参考最多两次生成：首轮与可选的一次定点修正，不做第三次。修订技能后也不重置该参考的次数；旧同图多轮只作为历史诊断。未达标时先查最早偏差，确有可复用修正再换新参考测试。视频迭代另按本次授权范围处理，不从图片授权扩张。范围不明确时不自动开启无上限重试、收费平台切换或批量生成。

## 对照方式

实际查看原参考和生成结果，先检查整体再检查局部。展示可访问的原参考与结果，或明确链接到对应文件；需要局部放大时标清位置，保留未修改原件。不能通过裁切、调色、改图或剪辑使结果看起来更接近后，再把它记作原始生成表现。

用以下维度定位差异，不固定打百分制：

| 维度 | 核心检查 |
| --- | --- |
| 主体和关键外观 | 数量、可辨特征、服装或结构、关键物件与文字 |
| 构图和空间 | 主体位置及占比、裁切、视角、前中后景、遮挡与距离关系 |
| 姿态和状态 | 朝向、视线、肢体姿态、接触和物件状态 |
| 光色和质感 | 受光方向、明暗布局、色彩分配、材质与成像纹理 |
| 视频时间表现 | 动作顺序、方向、速度变化、运镜、镜头时长与切点、连续性及已支持声音 |

相似度目标按用户本次约定记录在试验条件中。80%—85%之类数字是近似验收意图，不是纯文字生成工具的相似度旋钮；如用主观量表，生成前说明准则与停止条件，旧成绩不随目标改变而重写，也不把分数当像素一致率。达到可接受下限且关键关系无明显错误即可收尾，不为追求区间上沿继续刷图。

按生成前确定的目标，对每个决定性维度给“接近 / 有明显差异 / 未能验证”及具体证据。主体类别或基本构图明显不同，不能以色调相似掩盖；风格优先且已排除精确身份、微小道具等细节时，不事后加回扣分。主观分档与成对偏好发生分歧，保留具体维度的取舍，不强合成唯一胜负。需要视觉评分锚点时使用实际例图并注明是否经用户认可；文字校准不等于人类视觉共识。视频只有抽帧证据时不能给连续动作通过结论。

## 修正与结束

先修最影响相似度的差异；用户明确优先级时按其目标。图片按本图实际对照决定主体、布局、姿态、光色与质感的处理顺序；整体成像可以优先于局部外观细节，不固定每图先修内容或画质。首轮前观察复核的三处上限不作为图片返修额度；一次定点修正覆盖选定主要问题及其直接冲突，保留已正确且无关的内容。视频仍通常先处理主体、布局与姿态，再处理光色与细节。

指出“画面哪里不同 → 最早在哪一环偏离 → 本次改哪一属性、保留哪些属性”，在反推环节形成精确差量并同步完整正文与摘要；图片按[修订保留检查](image.md#修订时保留已正确的属性)核对，视频另检查时间、动作触发与声音范围。再调用同一格式器，以“上一版完整复制层＋差量”返回完整新版。明确文字仍未执行时不要倒推成上游漏写。

每次失败以具体可见约束为单位定位最早偏差，沿“原图可见事实 → 观察记录 → 完整内容稿 → 最终复制层/实际请求 → 输出”回查现有材料：漏看或误判、观察转正文时漏写或改变程度、格式器遗漏或改意、明确文字仍未执行。一个画面可以同时存在几类问题；例如某个位置已写却偏离，不能因此把同处尚未说清的边界也算成生成未遵守。材料不足就标出未能定位的环节，不补造调用记录。

已明确且相互一致的要求仍未实现时，保留该反例，不因失败自动强化形容词、增加坐标或改写正确事实。剩余允许次数内若尝试换一种说法，先说明要消除的具体歧义或要检验的表达假设；没有明确假设时如实保留未解决项，不假称重写会有效。多项一起返修属于整稿修正，不能将结果变化归功于某一句。图片首轮与第二轮分别记录；评价新版本用未参与该版修订的新图首轮，不能只展示最高分。

怀疑模板、顺序、表达效力或随机性时，先核对源图与最终文字，再按[诊断对照](diagnostic-comparison.md)选择一个要排除的原因。普通首轮加综合返修不冒充单变量实验；未经对照不能因分数停滞宣称模型到顶。

尽量维持同一工具和可控设置，不能把同时更换模型与提示词后的改善单独归因于提示词。输出含随机变化时说明，单轮对照只能支持当前结果判断。

达到用户指定的验收要求或本轮授权上限就结束；反复同类差异没有改善、工具失败或无法取得真实结果时停止无效重试，交付当前可用提示词、差异与具体限制。必要时可提出参考辅助重建作为另一种选择，但不能自行切换，更不能称其满足本阶段纯提示词条件。

“当前结果接近参考”要有实际对照依据，并保留残留差异；用户是否接受单独注明。只有用户认可时才说“用户已认可”，只有重复实测时才讨论稳定性。

需保存试验时，最少保留：参考路径、完整提示词及版本、实际工具/设置、生成输入未带参考的依据、输出路径、真实差异、用户决定和下一步。只有试验状态发生变化才更新，不搭建评分数据库或风格库。
